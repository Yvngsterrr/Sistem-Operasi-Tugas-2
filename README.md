3. Tugas Percobaan 3 group
   Buka file $cat /etc/group kemudian analisa untuk root:x:0
<img width="572" height="113" alt="3tugas1" src="https://github.com/user-attachments/assets/d6cceac1-61a5-4755-a993-162a84620b07" />
<img width="101" height="37" alt="3tugas2" src="https://github.com/user-attachments/assets/4dc0d040-148a-4436-a78f-07b8a8425acd" />
divided into 4 colon-separated (:) fields:
group_name:password:GID:user_list
- root: Is a group name that from primary superuser
- x: Is an encrypted group password
- 0: Is an ID number for the group, number “0” is exclusively for superuser(root)
- Empty field after “0:”: should represent list of secondary member in the
group
